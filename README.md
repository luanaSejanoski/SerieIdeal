# 🎬 SerieIdeal

Sistema web para catálogo e avaliação de séries, desenvolvido em PHP e MySQL.

## 📖 Sobre o Projeto

O SerieIdeal é uma plataforma que permite aos usuários visualizar séries, pesquisar por título ou gênero, realizar avaliações e comentar sobre suas séries favoritas.

O projeto foi desenvolvido utilizando a arquitetura MVC (Model-View-Controller), promovendo a separação entre regras de negócio, interface e controle das requisições.

---

## 🚀 Funcionalidades

### Usuário

- Cadastro de conta
- Login e logout
- Busca de séries por nome
- Busca de séries por gênero
- Visualização de detalhes das séries
- Avaliação com notas
- Comentários em séries
- Visualização da média de avaliações

### Administrador

- Cadastro de séries
- Gerenciamento do catálogo
- Cadastro de categorias/gêneros

## 🔒 Segurança

O projeto possui:

- Proteção CSRF
- Senhas criptografadas com `password_hash()`
- Verificação de login por sessão
- Consultas utilizando Prepared Statements (PDO)
